feat(chores): ごみの日・掃除ルーティーン・献立と買い物を追加

家事タブを足し、ごみ・掃除・ごはんの 3 機能を入れる。AI が無くても全機能が動き、
任意の AI 補助は無料枠だけで既定 OFF。

- ごみ: カレンダーの予定を「ごみの日」に分類する（この回だけ／シリーズ全体）。
  前日 20:00 の通知は既存の event_reminders へつなぐ。
- 掃除: ルーティーン（固定の日・実施した日から数える）。1 タップで完了・取り消し・
  スキップ。実施した日から数える回をスキップすると、次回はその回の予定日（JST）から
  1 周期後。
- ごはん:
  - 食材・今あるもので・7 日の献立・買い物。
  - 使わない食材。消費者庁の対象 29 品目と自由入力。
  - 取り分けの案内。
  - 購入・補充・作った料理への充当を分けて持ち、「作った」の取り消しは自分の分だけを
    戻す。
  - 料理が在る日へ 1 品だけ足せる。
  - 手で入れた料理は、使わない食材に当たるか原材料が分からなければ確定を止める。
    確定済みの料理は、当たる内容へ直すと提案へ戻す。
  - 除外を後から足した時、当たる確定の料理の材料は買い物の計算から外し、理由を出す。
  - 「作った」・購入・補充の RPC は、書く前に充当の台帳を枠の今の状態へ合わせる。
- 保存: 遅れて届いた応答は、同じ編集の回のときだけシートを閉じ、入力を消す。
- DB: 加算のみの migration 3 本。新しい 13 表は SELECT の RLS だけを持つ。書き込みは
  認可した SECURITY DEFINER RPC だけ（search_path=''、PUBLIC と anon は EXECUTE なし）。
- 検証:
  - pgTAP 4 本。権限の横断検査 chores_rpc_security を含む。
  - 実 Auth の JWT で RPC を直に呼ぶ e2e。
  - 2 接続の並行試験を E2E ジョブに足した。
  - 家事の Playwright。
