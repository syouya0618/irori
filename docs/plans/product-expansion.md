# 製品拡張の実装・検証台帳

本番適用・merge は対象外。合成データだけで検証し、フェーズごとに配送可能な単位を残す。

## 順序と移行境界

1. 計測と重複取得の削減。
2. 確定入力の量候補、公開済み更新履歴の開閉。
3. 世帯・閲覧専用・期限付き共有のDB権限。
4. 任意地域の公式ニュース。既存通知と失敗境界を分ける。
5. 複数児への expand/backfill、健診・接種、睡眠、成長参照、カスタム記録、年齢別表示。

旧版PWAの再送、保存結果不明、子どもの切替、共有取消後のキャッシュが移行の重点。
削除や推測による過去データ補完は行わない。参照データは権利を確認するまで同梱しない。

本人プロフィールを再利用する。既存Link/loading/並列取得、キャッシュTTL、再接続時の再取得は維持。

`scripts/measure-navigation.mjs` は別プロセスの合成HTTPサービスと production build を使う。
APIは `127.0.0.1:55439`、アプリは `127.0.0.1:55438`。ブラウザは一時プロファイル。
実行前に合成URL・合成公開キーでビルドする。本番・外部Supabaseには接続しない。
